FGCU Construction Management - Fall 2026

OPEN THE APP
Double-click index.html to open the app in Microsoft Edge or Google Chrome.
No installation or internet connection is needed to view the results.
The program and social media links require internet access.

OPTIONAL LOCAL SERVER
From PowerShell in this folder, run:
  node server.cjs
Then open http://localhost:3000
Press Ctrl+C in that PowerShell window to stop the server.

FEATURES
- Shared program results and the 2019-2026 enrollment chart
- Industry partner and prospective student audience tabs
- Original text, tables, and images from all three source handouts
- Search inside each handout and download its original Word document
- Social links decoded from the supplied handout's QR codes
- Print or save the current audience view as PDF
- Print format: US Letter, portrait orientation, 1-inch margins
- Responsive layout and keyboard-accessible audience tabs

content and tables but does not reproduce Word page layout or typography.
Changes to the Word documents do not automatically update the app.

The app uses plain HTML, CSS, and JavaScript without dependencies.
The optional local server uses only Node.js built-in modules and listens on
127.0.0.1 so it is accessible only on your computer.
